# Приложения из AppImage. Ставятся в ~/AppImages, .desktop и иконка
# генерируются скриптом (иконки лежат в local/share/appimages-icons/).
#
# Установка:  ./install.sh -A
#
# Формат (8 полей, разделитель |):
#   1. id          — имя файла <id>.appimage и <id>.desktop
#   2. версия      — на ней снят .desktop (X-AppImage-Version)
#   3. имя         — Name= в меню
#   4. wmclass     — StartupWMClass (пусто = -)
#   5. mimetype    — через ";" (пусто = -)
#   6. аргументы   — что дописать в Exec до %U (пусто = -)
#   7. прямая ссылка — качать автоматически; "-" = ссылка нестабильная
#   8. страница    — куда идти руками, если ссылка "-"
#
# Ссылки на "-" (TickTick, LM Studio, LM Studio Hub) отдаются вендорами с
# подменой URL, поэтому автоматом не качаются — install.sh напечатает ссылку.
